# CS 305 Software Security

This repository will be used as part of my computer science portfolio for CS 305 Software Security.

## About This Repository

This repository contains coursework and project materials related to secure software development. The main focus of this course is learning how to identify vulnerabilities, apply secure coding practices, use encryption and hashing techniques, and test software for security issues.

## Course Focus

In CS 305, I practiced important software security concepts, including:

* Secure communication using HTTPS
* Certificate generation with Java Keytool
* Checksum verification using SHA-256
* Static testing with OWASP Dependency-Check
* Manual code review for syntax, logic, and security issues
* Secure coding best practices
* Vulnerability assessment and mitigation

## Portfolio Purpose

The purpose of this repository is to show my growth as a computer science student and demonstrate my ability to apply secure software development practices. The work added here will help document my experience with software security tools, secure communication, and vulnerability testing.
